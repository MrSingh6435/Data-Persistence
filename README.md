# 🎮 Real-Time 3D Experience Project (Unity Pathways)

This project was built by following the **Unity Official Real-Time 3D Pathways**.  
It demonstrates the full design-to-development workflow while teaching fundamental **OOP concepts**, **scene flow**, and **JSON data persistence** in Unity.

---

## 📌 Project Overview

This project focuses on how a digital experience is designed and then built inside a real-time 3D engine like Unity.  
It follows the design pipeline taught in Unity Learn:

- Problem Identification  
- User & Market Research  
- Persona Creation & Use Cases  
- Preliminary Designs  
- Prototyping  
- Iterative Development (Design → Build → Test → Refine)

Through this learning path, I implemented programming fundamentals and core Unity techniques to bring the experience to life.

---

## 🎯 What I Learned

### 🔹 1. Object-Oriented Programming (OOP)

- Classes, Objects & Scripts  
- Encapsulation, Inheritance, Polymorphism  
- Script modularity and clean code organization  
- Reusable and maintainable components  

### 🔹 2. Scene Flow & Architecture

- Managing multiple Unity scenes  
- Smooth scene transitions  
- Persistent objects using `DontDestroyOnLoad`  
- Manager scripts (MainManager, UI Manager, Game Manager)

### 🔹 3. JSON Data Persistence

- Saving and loading data using JSON  
- Storing values like colors, settings, and player choices  
- Using `JsonUtility` for data serialization  
- Keeping data continuous across scenes

### 🔹 4. Design & Production Process

- Understanding the real-time production cycle  
- Pre-production → Production → Post-production  
- Agile iteration and feedback loops  
- Applying design thinking for better user experience
